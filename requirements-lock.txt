# 依赖冻结清单（lockfile）：由 pip freeze 生成并逐条精确 pin，含传递依赖与构建工具。
# 两个用途：
#   1) release.yml 以 -c 约束安装，exe 构建版本可复现、可审计；
#   2) 让 Dependabot 的安全告警覆盖 starlette/pydantic/anyio 等传递依赖
#      ——只有 >= 下限的清单看不见它们，抬下限也护不到它们。
# 重生成口径（每次动依赖后必做，详见 docs/CONTRIBUTING.md「依赖更新」四步）：
#   .venv\Scripts\python -m pip install -U -r requirements.txt -r requirements-dev.txt pyinstaller
#   .venv\Scripts\python -m pytest tests -q          # 全绿才允许冻结
#   重生成 body（整行复制执行；保留本文件 # 头部，只换后面的 pin 行）：
#   .venv\Scripts\python -c "import pathlib,subprocess as s;p=pathlib.Path('requirements-lock.txt');h=[l for l in p.read_text(encoding='utf-8').splitlines() if l.startswith('#')];b=sorted([x for x in s.run(['.venv/Scripts/python.exe','-m','pip','freeze'],capture_output=True,text=True).stdout.split() if x],key=str.casefold);p.write_text('\n'.join(h+b)+'\n',encoding='utf-8')"
# body 规则：pip freeze 的每行 `name==version`，按整行 casefold 升序排列
# （tests/test_deps_lock.py 会校验排序，乱序即红；固定顺序是为了 diff 只反映真实变更）。
# 编码硬性要求：UTF-8 无 BOM；PowerShell 下禁用 `Set-Content -Encoding ascii`
# （会把头部中文注释压成问号），用 Python 的 write_text(encoding="utf-8") 或
# [System.IO.File]::WriteAllLines($path, $lines, (New-Object System.Text.UTF8Encoding($false)))。
# 结构自洽由 tests/test_deps_lock.py 机械核对：精确 pin、覆盖清单下限、安全底线不回落、
# 构建工具被冻结、无重复条目、body 已排序。手改本文件不被禁止，但改完必须跑守卫。
