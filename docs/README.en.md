## What is this

RenPySlim helps Ren'Py game developers make their games **smaller, tidier, and ready to ship** — in one pipeline:

- **Analyze** — scan for oversized assets and produce a size/issues/recommendations report
- **Compress** — slim images, audio, video, and fonts; script references are rewritten automatically; default preset is quality-first (q95 near-lossless) and parallel optimization scales across CPU cores
- **Package** — build PC / Mac / Android releases via the official SDK
- **Dist slimming** — safely slim an already-packaged game (folder or zip/7z/rar), in and out
- **APK slimming** — Android builds too: images → WebP, audio → OGG (runtime remapping, no reference edits), automatic re-signing
- **Decompile unlock** (experimental) — for releases without sources, the bundled unrpyc recovers the scripts so even archived images/audio can be converted, then repacked into their RPA archives

Plus a project health check suite: unused-asset detection, pre-package junk cleanup,
duplicate-file detection, and missing-glyph reports — with the official lint
running automatically after every optimization.

**Safe by default**: every operation works on a copy first, originals untouched;
"don't replace unless it got smaller"; assets without found references are never
renamed; every run produces an analysis report and a change log.

## Quick start

**Regular users**: download `RenPySlim.exe` from
[Releases](https://github.com/AxelBeary/renpyslim/releases), double-click to run —
the browser opens the interface automatically.

**Developers**:

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
python main.py            # launch the GUI
```

## Graphical interface (recommended)

Sidebar layout, supporting **中文 / English / Русский / Español / Português (BR) / Türkçe / Deutsch / Français** and
**light/dark themes** (switch in the top-right corner; without a manual choice it
follows the browser language and system appearance, and your choice is remembered).
Four entry points: **Slim & Pack / Dist Slimming / APK Slimming / Font Slimming**.

### Four-step guided flow

1. Enter a path (or click "Browse archives/Browse folders"), click "Scan & analyze" → review the report
2. Tick the optimizations you want and pick a compression preset
3. Click "Run" → watch live progress and logs
4. Get the optimized result / official release packages

### Convenient operations

- **Drag a zip / 7z / rar / APK / folder onto the tool icon** — it fills in automatically and opens the matching feature
- Dropping a new file while the tool is running opens a new tab instead of launching again
- Recently used paths are kept in "Recent" for one-click reuse

### The four entry points

- **Slim & Pack**: point at a project directory; after optimization the official SDK builds the packages (PC/Mac/Android); optionally "pack assets into an RPA archive" (official channel)
- **Dist Slimming**: point at a release folder or drop a zip / 7z / rar (auto-extract, slim, auto-repack for delivery; password-protected archives supported); RPA archives are unpacked, optimized, and rebuilt automatically; if the archive contains an APK it transfers to safe APK slimming; the experimental "decompile scripts to unlock format conversion" option lets source-less releases benefit from format conversion too
- **APK Slimming**: pick a .apk file, three steps done (preset / max-slim toggle / signing choice — new key generated by default), producing an installable slimmed package
- **Font Slimming** (standalone): no game project needed — pick a font + text sources; ttc/otc collections are split by weight; originals are never overwritten; a used-character list is included

### Runtime safeguards

- Click "Stop" any time during a run (completed work is kept); failures automatically write a crash dump
- The UI notifies you when a new version is available (compared against GitHub Releases)
- If FFmpeg / 7-Zip is missing, the UI shows concrete install steps (winget command or download link)
- To quit: right-click the tray icon → Quit, or use the sidebar's "Quit tool" button (closing the browser tab does not stop the tool)

## Headless mode (for scripts/automation, JSON output throughout)

```
python cli.py env                                  # environment check
python cli.py analyze <path> --mode project        # analyze
python cli.py optimize <path> --preset balanced    # optimize
python cli.py full <project> --platforms pc,mac    # optimize + package in one go
python cli.py slimfont <font> <text sources...>    # standalone font slimming
python cli.py slimapk <apk> --remap --gen-key      # APK slimming (WebP/OGG + re-sign)
```

> AI assistants / automation scripts: read [AGENTS.md](../AGENTS.md) first (safety rules and troubleshooting included).

## Requirements

| Dependency | Used for | Notes |
|---|---|---|
| Ren'Py SDK | Packaging, compiling APK remap scripts | Usually auto-detected; otherwise set it in Settings |
| FFmpeg | Audio/video optimization | On PATH or in the bin folder next to the app |
| Java/JDK | Android packaging, APK re-signing | First-time Android packaging requires completing Android setup in the Ren'Py launcher |

The UI service listens on 127.0.0.1:52786 (an uncommon port) by default; if busy it
falls back to a system-assigned free port. Set `RENPYTOOLS_PORT` to override.

## Safety mechanisms

| Mechanism | Description |
|---|---|
| Working copy | Operates on a copy by default — not a byte of the original is touched |
| Forced backup | When "modify originals directly" is ticked, a full backup archive (including saves) is created first |
| No smaller, no replace | Each optimizer writes a temp file and only replaces when the size actually shrank |
| Reference gating | Assets without literal references in scripts are compressed in place, never renamed |
| Engine-dir protection | In dist/APK modes renpy/, lib/, assets/x-renpy/ are never touched |
| Mark, don't delete | Files suspected of being unreferenced only appear in the report by default; with the option enabled they move to quarantine |
| Junk cleanup removes only regenerable items | Caches/logs/bytecode; skipped automatically in modify-originals mode to protect saves |
| Images never declared dead | Ren'Py auto-loads images by filename — no reference found ≠ unused |
| Malicious-input protection | Whitelisted deserialization of archive indexes; path sanitization of archive entries (zip-slip defense) |
| Local-only | The service listens on 127.0.0.1 only and verifies request origins — unreachable from the network |
| Auto lint after optimization | The official static check is built into the pipeline, archived as validation.txt |
| Change log | Every run writes changelog.json recording each modification |

## Security boundary

- The service **listens on 127.0.0.1 only** (a local-only address): other devices on
  the LAN or the internet simply cannot connect. No firewall configuration needed,
  and exposing it in any way is discouraged;
- The tool does not offer, and will not offer, a "open network access" option. If you
  modify the source yourself, it is **strongly discouraged** to change the listen
  address to 0.0.0.0 or a public address — the UI has no login authentication, and
  exposing it hands local file read/write capability to anyone who can reach it;
- The tool itself makes no outbound requests, with one exception: "check for updates"
  (compared against GitHub Releases; failures are skipped silently and never affect functionality).

## Tests

```
.venv\Scripts\python -m pytest tests -q
```

Covers RPA archive read/write (both format generations plus malicious-archive
blocking), reference-rewrite safety, font/image optimizers not corrupting originals,
rpyc parsing, APK slimming (engine protection / signature removal / x- prefix path
translation / key generation), cancellation and crash dumps, safe defaults, review-fix
regressions, backend local-only guard, and eight-language i18n dictionary completeness — 114 tests.
