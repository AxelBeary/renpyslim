# RenPySlim

一站式的 Ren'Py 资源优化与打包工具：分析过大资源、压缩图片音频、字体瘦身、
自动改写脚本引用、调用官方 SDK 打包，以及对已打包成品做安全瘦身。
连安卓 APK 也能瘦：同名压缩基础上支持图转 WebP、音转 OGG（运行时重映射
透明换文件，不改引用），重打包后可自动重签名。
附带工程体检四件套：废资源检测（确认无引用的音频/视频/字体，可隔离）、
打包前垃圾清理（缓存/日志/存档）、内容重复文件检测、字体缺字报告，
并在每次优化后自动跑官方 lint 验证。

**维护者/Agent 请先读：**
- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)：架构蓝图、安全红线、扩展指南
- [docs/BACKLOG.md](docs/BACKLOG.md)：需求存档与待办（新需求先落这里）

默认安全：所有操作先复制到工作副本，原件不动；"没变小就不替换"；
找不到引用的资源绝不改名；每次执行都产出分析报告和修改清单。

## 两种用法

### 图形界面（推荐）

双击 `dist\RenPySlim.exe`（或开发模式运行 `python main.py`），
浏览器会自动打开操作页面，跟着四步引导走即可：

1. 填路径（或点"浏览压缩包/浏览文件夹"弹出选择框），点"扫描分析" → 看分析报告
2. 勾选要做的优化项、选压缩档位
3. 点"开始执行" → 实时看进度日志
4. 完成后拿到优化结果 / 官方发布包

省事操作：
- 把 zip / 7z / rar / 文件夹直接拖到工具图标上，自动填入并开始分析
- 工具已在运行时再拖入新文件，会自动开新标签页处理，不会重复启动
- 用过的路径记在"最近用过"里，一点即用

退出方式（关浏览器页面不会停掉工具）：
- 右下角托盘图标右键 → 退出工具
- 或页面底部的"退出工具"按钮

- "超级打包器"标签：输入工程目录，优化后自动调官方 SDK 打包（PC/Mac/Android），
  可勾选"打包时把资源封进 RPA 封包"（官方通道）
- "成品瘦身"标签：输入成品目录或直接丢 zip / 7z / rar 压缩包（自动解压、
  瘦身后自动重新打包交付，支持带密码的压缩包）；遇到 RPA 封包自动拆开优化再重建
- 执行中可随时点"停止任务"（已完成的部分保留）；任务失败自动落盘崩溃转储；
  有新版时环境栏会提示（对比 GitHub Releases）
- "字体瘦身"标签（独立工具）：不需要游戏工程，选字体 + 文本来源即可瘦身；
  ttc/otc 集合自动拆开按字重分别输出；永不覆盖原件，并附赠使用字符清单
- 工程分析报告支持下载"使用字符清单"；优化输出目录里也会存一份 charlist.txt
- 缺 FFmpeg / 7-Zip 时，界面会给出具体安装方法（winget 命令或下载地址）

### 无头模式（供脚本/自动化调用，全程 JSON 输出）

```
python cli.py env                                  # 环境体检
python cli.py analyze <路径> --mode project        # 分析
python cli.py optimize <路径> --preset balanced    # 优化
python cli.py full <工程路径> --platforms pc,mac   # 优化+打包一条龙
python cli.py slimfont <字体> <文本来源...>        # 独立字体瘦身
python cli.py slimapk <apk> --remap --gen-key      # APK 瘦身（图转WebP/音转OGG+重签名）
```

## 环境要求

- Ren'Py SDK（打包与 APK 重映射脚本编译需要，一般自动找到；找不到在界面"设置"里指定）
- FFmpeg（音频优化需要；已装到 PATH 或放入程序旁 bin 目录均可）
- Java/JDK（安卓打包与 APK 重签名需要；安卓打包首次需先在 Ren'Py 启动器完成安卓配置）

界面服务默认监听 127.0.0.1:52786（冷门端口），被占用时自动改用
系统分配的空闲端口；可用环境变量 RENPYTOOLS_PORT 指定其他端口。

## 安全机制一览

| 机制 | 说明 |
|---|---|
| 工作副本 | 默认复制到副本再动刀，原件一个字节不动 |
| 强制备份 | 勾选"直接修改原文件"时先生成完整备份压缩包 |
| 没变小不替换 | 每个优化器先写临时文件，确认体积变小才替换 |
| 引用门控 | 脚本里找不到字面引用的资源只原地压缩，绝不改名 |
| 引擎目录保护 | 成品/APK 模式下 renpy/、lib/、assets/x-renpy/ 一律不碰 |
| 只标记不删除 | 疑似无引用文件默认只进报告，开启选项后也是移入隔离区 |
| 垃圾清理只删可再生项 | 缓存/日志/字节码；直接改原件模式下自动跳过以保护存档 |
| 图片不判废 | Ren'Py 按文件名自动加载图片，查不到引用不等于没用 |
| 优化后自动 lint | 官方静态检查内置到流程，输出存档 validation.txt |
| 修改清单 | 每次执行输出 changelog.json，记录每一处改动 |
