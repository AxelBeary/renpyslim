## 这是什么

RenPySlim 帮 Ren'Py 游戏开发者把作品**变小、变整齐、打包发布**，一条龙：

- **分析**——扫描过大资源，给出体积/问题/建议报告
- **压缩**——图片、音频、视频、字体全面瘦身，自动改写脚本引用；
  默认档位画质优先（q95 近无损），并行优化自动吃满多核
- **打包**——调用官方 SDK 出 PC / Mac / Android 发布包
- **成品瘦身**——对已打包的游戏（目录或 zip/7z/rar）安全瘦身，直进直出
- **APK 瘦身**——安卓包也能瘦：图转 WebP、音转 OGG（运行时重映射，不改引用），自动重签名
- **反编译解锁**（实验性）——无源码成品用内嵌的 unrpyc 找回源码，
  封包内的图片/音频也能转格式，转换后按原样包回 RPA 封包

附带工程体检四件套：废资源检测、打包前垃圾清理、重复文件检测、
字体缺字报告，并在每次优化后自动跑官方 lint 验证。

**默认安全**：所有操作先复制到工作副本，原件不动；"没变小就不替换"；
找不到引用的资源绝不改名；每次执行都产出分析报告和修改清单。

## 快速开始

**普通用户**：到 [Releases](https://github.com/AxelBeary/renpyslim/releases)
下载 `RenPySlim.exe`，双击运行，浏览器自动打开操作页面。

**开发者**：

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
python main.py            # 启动图形界面
```

## 图形界面（推荐）

界面为侧边栏布局，支持**中文 / English / Русский / Español** 与
**亮色/暗色双主题**（右上角切换；不手动选时跟随浏览器语言与系统外观，
选择会被记住）。四个入口：**超级打包器 / 成品瘦身 / APK 瘦身 / 字体瘦身**。

### 主流程四步引导

1. 填路径（或点"浏览压缩包/浏览文件夹"弹出选择框），点"扫描分析" → 看分析报告
2. 勾选要做的优化项、选压缩档位
3. 点"开始执行" → 实时看进度条与日志
4. 完成后拿到优化结果 / 官方发布包

### 省事操作

- 把 zip / 7z / rar / APK / 文件夹**直接拖到工具图标上**，自动填入并进入对应功能
- 工具已在运行时再拖入新文件，会自动开新标签页处理，不会重复启动
- 用过的路径记在"最近用过"里，一点即用

### 四个功能入口

- **超级打包器**：输入工程目录，优化后自动调官方 SDK 打包（PC/Mac/Android），
  可勾选"打包时把资源封进 RPA 封包"（官方通道）
- **成品瘦身**：输入成品目录或直接丢 zip / 7z / rar 压缩包（自动解压、
  瘦身后自动重新打包交付，支持带密码的压缩包）；遇到 RPA 封包自动拆开优化再重建；
  压缩包里装的是 APK 时自动转入 APK 安全瘦身；高级选项里的实验开关
  "反编译脚本解锁格式转换"可让无源码成品也吃到格式转换红利
- **APK 瘦身**：选 .apk 文件三步搞定（档位/最大瘦身开关/签名三选一，
  默认自动生成新钥匙），产出能直接安装的瘦身后包
- **字体瘦身**（独立工具）：不需要游戏工程，选字体 + 文本来源即可瘦身；
  ttc/otc 集合自动拆开按字重分别输出；永不覆盖原件，附赠使用字符清单

### 运行保障

- 执行中可随时点"停止任务"（已完成的部分保留）；任务失败自动落盘崩溃转储
- 有新版时界面会提示（对比 GitHub Releases）
- 缺 FFmpeg / 7-Zip 时，界面会给出具体安装方法（winget 命令或下载地址）
- 退出方式：右下角托盘图标右键 → 退出工具，或侧边栏左下角"退出工具"按钮
  （关浏览器页面不会停掉工具）

## 无头模式（供脚本/自动化，全程 JSON 输出）

```
python cli.py env                                  # 环境体检
python cli.py analyze <路径> --mode project        # 分析
python cli.py optimize <路径> --preset balanced    # 优化
python cli.py full <工程路径> --platforms pc,mac   # 优化+打包一条龙
python cli.py slimfont <字体> <文本来源...>        # 独立字体瘦身
python cli.py slimapk <apk> --remap --gen-key      # APK 瘦身（图转WebP/音转OGG+重签名）
```

> AI 助手 / 自动化脚本调用前请先阅读 [AGENTS.md](AGENTS.md)（含安全规则与报错排查）。

## 环境要求

| 依赖 | 用途 | 说明 |
|---|---|---|
| Ren'Py SDK | 打包、APK 重映射脚本编译 | 一般自动找到；找不到在界面"设置"里指定 |
| FFmpeg | 音频/视频优化 | 装到 PATH 或放入程序旁 bin 目录均可 |
| Java/JDK | 安卓打包、APK 重签名 | 安卓打包首次需先在 Ren'Py 启动器完成安卓配置 |

界面服务默认监听 127.0.0.1:52786（冷门端口），被占用时自动改用系统分配
的空闲端口；可用环境变量 `RENPYTOOLS_PORT` 指定其他端口。

## 安全机制一览

| 机制 | 说明 |
|---|---|
| 工作副本 | 默认复制到副本再动刀，原件一个字节不动 |
| 强制备份 | 勾选"直接修改原文件"时先生成完整备份压缩包（含存档） |
| 没变小不替换 | 每个优化器先写临时文件，确认体积变小才替换 |
| 引用门控 | 脚本里找不到字面引用的资源只原地压缩，绝不改名 |
| 引擎目录保护 | 成品/APK 模式下 renpy/、lib/、assets/x-renpy/ 一律不碰 |
| 只标记不删除 | 疑似无引用文件默认只进报告，开启选项后也是移入隔离区 |
| 垃圾清理只删可再生项 | 缓存/日志/字节码；直接改原件模式下自动跳过以保护存档 |
| 图片不判废 | Ren'Py 按文件名自动加载图片，查不到引用不等于没用 |
| 恶意输入防护 | 封包索引白名单反序列化；压缩包条目路径净化（防 zip-slip） |
| 本地专用 | 服务只听 127.0.0.1，并校验请求来源，外网无法访问 |
| 优化后自动 lint | 官方静态检查内置到流程，输出存档 validation.txt |
| 修改清单 | 每次执行输出 changelog.json，记录每一处改动 |

## 安全边界

- 服务**只监听 127.0.0.1**（"仅限本机"地址）：局域网与外网的其他设备
  根本无法建立连接，无需配置防火墙，也不建议以任何方式对外暴露；
- 工具不提供、也不计划提供"开放网络访问"选项；若自行修改源码，
  **强烈不建议**把监听地址改为 0.0.0.0 或外网地址——界面无登录鉴权，
  暴露等于把本机文件读写能力交给任何能访问的人；
- 工具自己不主动访问外网，唯一例外是"检查新版本"（对比 GitHub Releases，
  失败静默跳过，不影响任何功能）。
