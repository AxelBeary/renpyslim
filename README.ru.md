## Что это

RenPySlim помогает разработчикам игр на Ren'Py сделать игру **меньше, аккуратнее и готовой к выпуску** — в одном конвейере:

- **Анализ** — поиск раздутых ресурсов, отчёт по размеру/проблемам/рекомендациям
- **Сжатие** — облегчение изображений, аудио, видео и шрифтов; ссылки в скриптах переписываются автоматически; профиль по умолчанию — приоритет качества (q95, почти без потерь), параллельная обработка задействует все ядра процессора
- **Упаковка** — сборка релизов PC / Mac / Android через официальный SDK
- **Сжатие сборки** — безопасное облегчение уже упакованной игры (папка или zip/7z/rar), на входе и на выходе
- **Сжатие APK** — и для Android тоже: изображения → WebP, аудио → OGG (переназначение в рантайме, без правки ссылок), автоматическая переподпись
- **Декомпиляция для конвертации** (экспериментально) — для сборок без исходников встроенный unrpyc восстанавливает скрипты, и даже ресурсы внутри архивов можно конвертировать, а затем упаковать обратно в RPA

Плюс проверка здоровья проекта: поиск неиспользуемых ресурсов, уборка мусора перед
упаковкой, поиск дубликатов, отчёт об отсутствующих глифах — и официальный lint
запускается автоматически после каждой оптимизации.

**Безопасно по умолчанию**: все операции сначала работают с копией, оригиналы не
трогаются; «не уменьшилось — не заменяем»; ресурсы без найденных ссылок никогда не
переименовываются; каждый запуск выдаёт отчёт об анализе и список изменений.

## Быстрый старт

**Обычным пользователям**: скачайте `RenPySlim.exe` из
[Releases](https://github.com/AxelBeary/renpyslim/releases), запустите двойным
кликом — браузер сам откроет интерфейс.

**Разработчикам**:

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
python main.py            # запуск графического интерфейса
```

## Графический интерфейс (рекомендуется)

Боковая панель, поддержка **中文 / English / Русский / Español / Português (BR) / Türkçe / Deutsch / Français** и
**светлой/тёмной темы** (переключение в правом верхнем углу; без ручного выбора
следует языку браузера и системному оформлению, выбор запоминается).
Четыре входа: **Оптимизация и упаковка / Сжатие сборки / Сжатие APK / Сжатие шрифтов**.

### Пошаговый процесс (4 шага)

1. Укажите путь (или нажмите «Обзор архивов/Обзор папок»), нажмите «Анализ» → изучите отчёт
2. Отметьте нужные оптимизации и выберите уровень сжатия
3. Нажмите «Запустить» → следите за прогрессом и журналом в реальном времени
4. Получите оптимизированный результат / официальные пакеты

### Удобные операции

- **Перетащите zip / 7z / rar / APK / папку прямо на значок инструмента** — путь подставится сам и откроется нужная функция
- Если инструмент уже запущен, новый файл откроется в новой вкладке — без повторного запуска
- Недавние пути хранятся в «Недавние» — один клик и готово

### Четыре входа

- **Оптимизация и упаковка**: укажите папку проекта; после оптимизации официальный SDK соберёт пакеты (PC/Mac/Android); опционально «упаковать ресурсы в RPA-архив» (официальный канал)
- **Сжатие сборки**: укажите папку готовой сборки или перетащите zip / 7z / rar (авто-распаковка, сжатие, автоматическая переупаковка; поддерживаются архивы с паролем); RPA-архивы автоматически разбираются, оптимизируются и собираются заново; если внутри APK — автоматический переход к безопасному сжатию APK; экспериментальная опция «декомпилировать скрипты» открывает конвертацию форматов и для сборок без исходников
- **Сжатие APK**: выберите .apk-файл, три шага (уровень / режим максимального сжатия / подпись — по умолчанию создаётся новый ключ), на выходе — готовый к установке облегчённый пакет
- **Сжатие шрифтов** (автономно): проект игры не нужен — выберите шрифт + источники текста; коллекции ttc/otc разбиваются по начертаниям; оригиналы никогда не перезаписываются; прилагается список использованных символов

### Гарантии во время работы

- В любой момент можно нажать «Остановить» (выполненная часть сохраняется); при сбое автоматически сохраняется дамп
- Интерфейс сообщит о новой версии (сравнение с GitHub Releases)
- Если FFmpeg / 7-Zip не найдены, интерфейс покажет конкретный способ установки (команда winget или ссылка)
- Выход: правый клик по значку в трее → Выход, либо кнопка «Выход» внизу боковой панели (закрытие вкладки браузера не останавливает инструмент)

## Безголовый режим (для скриптов/автоматизации, вывод в JSON)

```
python cli.py env                                  # проверка окружения
python cli.py analyze <путь> --mode project        # анализ
python cli.py optimize <путь> --preset balanced    # оптимизация
python cli.py full <проект> --platforms pc,mac     # оптимизация + упаковка
python cli.py slimfont <шрифт> <источники...>      # автономное сжатие шрифтов
python cli.py slimapk <apk> --remap --gen-key      # сжатие APK (WebP/OGG + переподпись)
```

## Требования

| Зависимость | Зачем | Примечание |
|---|---|---|
| Ren'Py SDK | Упаковка, компиляция скриптов переназначения APK | Обычно находится сам; иначе укажите в «Настройки» |
| FFmpeg | Оптимизация аудио/видео | В PATH или в папке bin рядом с программой |
| Java/JDK | Сборка под Android, переподпись APK | При первой сборке под Android сначала завершите настройку Android в лаунчере Ren'Py |

Служба интерфейса по умолчанию слушает 127.0.0.1:52786 (редкий порт); если он занят,
автоматически выбирается свободный системный порт. Порт можно задать переменной
`RENPYTOOLS_PORT`.

## Механизмы безопасности

| Механизм | Описание |
|---|---|
| Рабочая копия | По умолчанию всё делается на копии — оригиналы не трогаются ни на байт |
| Обязательный бэкап | При выборе «менять исходные файлы напрямую» сначала создаётся полная резервная копия (включая сохранения) |
| Не уменьшилось — не заменяем | Каждый оптимизатор пишет во временный файл и заменяет только при реальном уменьшении |
| Контроль по ссылкам | Ресурсы без буквальных ссылок в скриптах сжимаются на месте и никогда не переименовываются |
| Защита папок движка | В режимах сборки/APK папки renpy/, lib/, assets/x-renpy/ не трогаются |
| Пометить, не удалять | Подозрительно неиспользуемые файлы по умолчанию попадают только в отчёт; с включённой опцией — в карантин |
| Уборка мусора удаляет только воссоздаваемое | Кэши/логи/байткод; в режиме правки оригиналов автоматически пропускается ради сохранений |
| Изображения не объявляются мёртвыми | Ren'Py загружает картинки по имени файла — нет ссылки ≠ не используется |
| Защита от вредоносного ввода | Десериализация индексов архивов по белому списку; очистка путей записей (защита от zip-slip) |
| Только локально | Служба слушает только 127.0.0.1 и проверяет источник запросов — извне недоступна |
| Авто-lint после оптимизации | Официальная статическая проверка встроена в конвейер, сохраняется как validation.txt |
| Список изменений | Каждый запуск пишет changelog.json со всеми изменениями |

## Границы безопасности

- Служба **слушает только 127.0.0.1** («только этот компьютер»): другие устройства в
  локальной сети или интернете просто не могут подключиться. Настройка файрвола не
  нужна; выставлять наружу каким-либо способом не рекомендуется;
- Инструмент не предоставляет и не планирует предоставлять опцию «открыть сетевой
  доступ». Если вы сами меняете исходники, **настоятельно не рекомендуется** менять
  адрес на 0.0.0.0 или публичный — у интерфейса нет входа и аутентификации, и
  публикация отдаёт доступ к файлам машины любому, кто сможет достучаться;
- Инструмент сам не обращается в интернет, единственное исключение — «проверка
  обновлений» (сравнение с GitHub Releases; при неудаче молча пропускается и ни на
  что не влияет).

## Тесты

```
.venv\Scripts\python -m pytest tests -q
```

Покрывают чтение/запись RPA-архивов (оба поколения форматов и блокировка
вредоносных архивов), безопасность переписывания ссылок, сохранность оригиналов при
оптимизации шрифтов/изображений, разбор rpyc, сжатие APK (защита движка / удаление
подписи / преобразование путей x- / генерация ключей), отмену и дампы сбоев,
безопасные значения по умолчанию, регрессии исправлений, локальную защиту бэкенда
и полноту словарей локализации для восьми языков — 114 тестов.
